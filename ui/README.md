# Basic AI Chat UI

React frontend for Basic AI Chat, built with Vite, TanStack Router, Tailwind CSS, shadcn/ui, and the Hono typed client.

## Development

```bash
npm install
cp .env.start.example .env.start
npm start
```

The UI runs at `http://localhost:5173` and talks to the API configured by `VITE_API_URL`.

## Scripts

- `npm start` - Start the Vite development server
- `npm run build` - Build for production
- `npm run preview` - Preview the production build
- `npm run compile` - Type-check the TypeScript code
- `npm run format` - Format code with Prettier
